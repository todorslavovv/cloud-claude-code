# cloud-claude-code

## Mathematics for Machine Learning and Deep Learning

The [`math-for-ml/`](math-for-ml) directory contains a complete set of lecture
notes, *Mathematics for Machine Learning and Deep Learning: From Absolute
Beginner to Prerequisites*, written in LaTeX.

* **Read:** [`math-for-ml/mathematics-for-ml-and-dl.pdf`](math-for-ml/mathematics-for-ml-and-dl.pdf)
* **Build and contribute:** see [`math-for-ml/README.md`](math-for-ml/README.md)

The notes start from basic arithmetic and cover algebra, functions, geometry,
linear algebra, single- and multivariable calculus, optimization, probability,
statistics and the mathematics of deep learning (softmax, cross-entropy,
backpropagation, attention), with worked examples, figures and 405 exercises
with solutions.
